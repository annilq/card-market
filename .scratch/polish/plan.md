# 方案：首页 / 卡片列表 / 卡片详情 / 公告 / 留言 / 门店 —— 动效 + 色彩优化

> 基线证据：`.scratch/visual-audit/shots/`（7 页 × 1440/390 × 浅色/深色，共 28 张）。
> 本文件是方案本身；实现落在分支 `feat/home-polish`（worktree `.worktrees/home-polish`）。

## 1. 定位：这不是「加动画、加颜色」，是修三处结构性缺陷

`animate` + `colorize` 的输入前提是「界面已经对了，只是平淡」。读过代码和截图后，真正的浪费在于别的：

| # | 缺陷 | 证据 | 代价 |
|---|---|---|---|
| A | **价格这一栏信息是断的** | 全站价格 `¥880.00`，仓库是 TCG 卡；后台价格是日元整数（种子 `price: 880.00`） | 买家每张卡都要在脑内去掉两位小数，价格不再可信 |
| B | **列表页在手机上是空的** | `/cards` 390px 首屏：筛选标题 + 排序 + 空行，第一张卡从 ~300px 才开始。`filtersOpen` 默认 `false`，但折叠体 `hidden` 依然占位 | 手机用户（主访客，X 导流）第一屏看不到一张卡 |
| C | **公告的日期栏在真实数据下是「—」** | 库里 2/3 条公告 `published_at = null`（发布即展示是合法状态），`formatDate` 对它返回「—」 | 公告页与详情页各有一行破折号，读起来像数据坏了 |

这三条先修，再谈动效与颜色——否则是把运动叠在一套错的消息上。

## 2. 色彩：给「收藏状态」一个色相，但仍只由颜色说一件事

**现状**：系统是冷石板 + 一支红（价格）。这没有任何问题，问题是**全站所有卡牌在视觉上是同一件东西**——买家要靠读小字去区分稀有度、区分精品（收藏柜）与散装。

**策略（增量，不换世界）**：保留红 = 钱、琥珀 = 高价买取。新增**一支紫色，只表达「柜藏级」**（`card_status = packaged`，即评级/密封/收藏柜中的卡）。

- 理由：卖家需要知道「你这张卡值不值得跑一趟」，而「柜藏级」正是日语圈 `高額買取` 的隐含条件。紫色在卡牌市场（评级卡壳、封套）有天然语义，且与红/琥珀距离够远，不会混淆。
- 作用面：只做**签名条**（卡片图位左上角 4px 竖条 + 详情页状态徽章），色面积极小，不构成「第二支暖色」，也不与价格抢眼。
- 稀有度**不上色**（SSR/UR/HR 是客户后台可自由增删的字典，硬编码色会错），改用**权重**：SSR/UR 提升到 600、HR/N 保持 500。颜色交给「柜藏级」，重量交给稀有度，两者不重复编码。

新增令牌（浅/深各一值，写入 `@theme` 与 `html.dark`）：

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--color-vault` | `#7c3aed` | `#c4b5fd` | 柜藏级签名条 / 徽章文字 |
| `--color-vault-bg` | `rgb(124 58 237 / .08)` | `rgb(196 181 253 / .14)` | 徽章底 |

`#7c3aed` 在白底 6.4:1，`#c4b5fd` 在夜卡 `#1e293b` 上 9.0:1。签名条本身不承载文字，只要求 3:1（与白卡片 6.4:1）。

## 3. 动效：一个作者时刻，其余是反馈

**运动命题**：这本目录是「一页一页翻」的。所以运动只做一件事——**从列表翻到卡片本身**（列表缩略图 → 详情大图的共享元素转场）。其余全部是操作反馈，不编排进场。

| 层 | 内容 | 时长 / 曲线 | 为什么值得存在 |
|---|---|---|---|
| **焦点时刻** | `view-transition-name` 按卡牌 id 绑定在卡片图位；列表/首页 → 详情时，图从格子里长成详情大图；详情返回列表时反向收缩 | 380ms `cubic-bezier(.16,1,.3,1)` | 它解释「你点的就是这一张」——上下文切换唯一的连续性。TanStack Router 1.170 原生支持 `viewTransition` |
| **反馈** | 卡片悬停：图 1.02→1.03、边框转强、价格行「落一格」；筛选选中：勾选框与计数淡变；提交按钮：提交中 spinner 与文案交叉淡变 | 140ms 反馈 / 220ms 状态 | 确认「已发生」 |
| **连续性** | 分页与筛选切换时，结果网格以 90ms 投影外扩淡入（`opacity` + 6px `translateY`，仅 12–24 个格子，不逐格 stagger） | 240ms 出、160ms 回 | 告诉用户「列表换了」，而不是闪一下 |
| **禁用** | 跑马灯自动轮播在 `prefers-reduced-motion` 下不自动走，只保留手动圆点；所有位移归零，颜色/透明度反馈保留 | — | 减少动态 ≠ 去掉反馈 |

实现到运行时：
- **不引任何动画库**。`view-transition` 用 Router 自带；其余是 CSS transition/keyframes + 一个 `useReducedMotion` 的判定。
- 内容默认可见：列表格子不写 `opacity:0` 初始态，animation 只做「从 0 到 1」的入场，脚本失败也只是不淡入。
- 背景模糊/滤镜不进入常规路径；`view-transition::view-transition-old/new` 只做 `transform + opacity`。

## 4. 逐页方案

### 4.1 首页 `/`
- **价格格式**：全站统一 `¥880`（`formatPrice` 已有，卡片/详情/留言回显都改走它）。金额仍保留两位小数的能力，但默认整数日元。
- **banner**：轮播保留，但改成「点圆点才动、悬停暂停、`prefers-reduced-motion` 下不自动」；底部圆点从 8px 圆点改为 24px 触控区（WCAG 2.5.8）。
- **通知公告**：行高 44px，日期列在窄屏折到标题下方；悬停整行底色 + 标题左侧 2px 墨色指示条（动的是 `border`，不是 shadow）。
- **高价买取**：横条首图加宽到 2:3 比例（原来 3:4 的 144px 宽在横条里太碎），价格行不再截断；右缘加「渐隐遮罩」提示可滚动（`mask-image`，纯 CSS）。
- **筛选 + 结果**：首页四联筛选下方加一行**活跃筛选 chips**（可单个移除），结果计数与 chips 同行；空结果面板给出「清空筛选」动作而不是一句话。

### 4.2 卡片列表 `/cards`
- **手机首屏修复**：`lg` 以下整个 `aside` 不渲染（不只是 `hidden`），筛选入口改成一行 36px **工具条**：「筛选 · 已选 n」+ 结果计数 + 排序下拉。第一张卡从 ~300px 提到 ~190px。
- **桌面筛选栏**：标题右侧显示已选计数（墨色 pill）。
- **不做分面计数**（原计划里的 `(12)`）：Directus 不返回分面统计，要另发聚合请求；宁可不显示，也不显示一个会过期的数字。
- **稀有度/柜藏级**：图位左侧 4px 紫签名条 + 左上角「有包装」实心徽章（见 §2）。徽章用实心卡片色而非半透明——压在照片上时对比度会由照片决定，浅色卡图上紫字只有约 2:1。稀有度不上色，改字重（SSR/UR 600，其余 400）。
- **分页**：切页后 `scrollRestoration` 回到网格顶端并聚焦网格容器（键盘用户不再落在页脚）。

### 4.3 卡片详情 `/cards/$id`
- **布局**：桌面维持 1:1，但把「价格 + 咨询」做成**右侧粘性块**（`md:sticky md:top-20`），长描述滚动时价格与 CTA 始终在视口内。手机端 CTA 变成底部 `fixed` 操作条（安全区内边距 + 页面预留等高 `pb`），不再要滚到描述末尾才看得到「咨询此卡」。
- **图片**：缩略图切换时主图 200ms 淡入（只在用户点过之后播，首帧不播）；键盘 ←/→ 切换；缩略图当前项 2px 墨色描边 + `aria-current`；图片组本身可聚焦并有令牌化的 focus ring。
- **信息补全**：`dl` 从 2 项扩到 4 项（卡牌状态、稀有程度、编号、上架时间），两列在手机上仍成立。
- **柜藏级徽章**：与「高价买取」并列，紫色（§2），不与价格抢位。
- **焦点时刻**：从列表/首页进入时缩略图 morph 成大图（§3）。

### 4.4 公告列表 `/announcements`
- 现状每条是**整行空白卡片 +「—」日期**（未设 `published_at` 时 `formatDate` 返回「—」）。改：未设发布时间**不渲染那一行**；列表改成单一容器 `divide-y`（与首页一致），每条左侧 2px 置顶指示条，右侧日期列。
- 空状态：一句说明 + 「回到卡牌」动作，而不是一行灰字。

### 4.5 公告详情 `/announcements/$id`
- 同样去掉「—」日期；标题上方保留返回链接但降到 12px；正文 `max-w-[68ch]`（当前 `max-w-2xl` 在 16px 下约 75ch，偏宽，CJK 尤其）。
- 正文首段提升到 18px/1.8（`prose` 作用域内，不改全站 body）。
- 底部加「其他公告」两条（同一 `getAnnouncements` 结果前端切片），让读到最后的人有下一步。

### 4.6 留言 `/message`
- **表单**：字段间距 20px，必填标记从红字改为墨色「必填」+ 星号（红只给错误）；错误/成功横幅沿用现有 `--color-success/--color-danger`，出现时 200ms 淡入。
- **附卡上下文**：卡片预览从 44×56 提到 56×72，价格用 `text-price` 展示（现在只是 `text-muted` 小字）。
- **提交中**：按钮锁定宽度，不因「提交中…」抖动；按钮内 spinner 16px，`aria-busy`。
- 提交成功后：滚动到成功横幅（目前只 `focus()`，在手机上焦点所在位置可能仍在屏幕外）。

### 4.7 门店 `/shops`
- 选中行：从 `shadow-sm + border-fg` 改为**墨色 2px 左侧签名条 + 浅表面**（去掉 shadow，符合 Flat-at-Rest），并加 `aria-pressed`。
- 门店图片：`h-20 w-24` → `h-[72px] w-24`，与三行地址块等高对齐。
- 地图侧反馈用**平移**（`setView` 到该店坐标），不做 marker 缩放——marker 是 SVG divIcon，缩放会让针尖偏离真实坐标。
- 手机端：「给我们留言」上移到列表顶部（当前在列表之后，需要滚过三张卡片）。
- 地图深色主题：Leaflet 瓦片在白底上，深色页里是一块亮斑。改用 `filter: invert(.92) hue-rotate(180deg)` 的瓦片层（`html.dark` 作用域，只作用于 `.map-tiles`）。marker 是独立 DOM 层，不受 filter 影响；它的颜色改为读 `--color-accent` / `--color-on-accent`，否则深色瓦片上的近黑针几乎消失。

## 5. 不做 / 明确回绝

- 不做逐区块滚入 stagger：这是 Operate/Read 面，不是落地页。
- 不做视差、粒子、渐变文字、彩色 glow。
- 不给稀有度硬编码色（后台可增删字典）。
- 不换字体（DESIGN.md「No-Display-Type」仍然成立）。
- 不引入任何第三方动画/UI 库。
