# 设计图实测规格（证据记录）

来源：`resources/*.png`（`-h-index.png` 首页、`帖子.png` 公告详情、`个人信息收集.png`、`会社概要.png`、`地址.png`），
画布 1920，PNG 元数据 72dpi（无缩放提示），内容列实测 360→1560 = **1200px** 且两侧无额外留白，
因此判定为 1× 设计稿：**所有数值按 1× 采用**。

取数方法：
- 色值：区域内众数色 / 墨迹主色（`/tmp` 下的 `measure` Swift 工具 + Pillow 采样）。
- 字号与间距：墨迹包围盒 + 逐列字形聚类（`measure`）+ macOS Vision OCR 的行坐标（`design-ocr`）。
- 版式：整幅降采样成字符图逐行比对（`scan.py` / Pillow）。

- 第三行用「卡牌状态」而不是附件的「罕见度」：罕见度提到了顶部那颗红胶囊上，
  我们没有独立的评级字段，再写一遍就成了同一信息两处。
- 附件里没有关闭按钮，补了一颗（Esc / 点遮罩 / 点它都能关）：关不掉的浮层等于坏了。

弹窗与详情页共用 `src/components/CardInfo.tsx`，详情页传 `nameAs="h1"`
（那一页需要一个标题级元素），弹窗用默认 div。

## 与设计的当前偏差（另一处会话改的，不是漏做）

下面这几项在量测脚本里按**当前值**断言（免得被再改一次还看不出来），
但与设计图实测值已经不符，若要回到设计稿就把它们改回来：

| 项 | 设计图实测 | 当前实现 |
| --- | --- | --- |
| 顶栏高度 | 100px | 96px（`md:h-24`） |
| banner → 通知条 | 0px（649→650） | 16px（首页整段改成 `space-y-4`） |
| 门店双列间距 | 61px | 24px |
| 结果栅格最宽列数 | 8 列 | 5 列（`lg:grid-cols-5`） |

## 有意偏差（不是漏做）

1. ~~未做 IP tab 条~~ —— 第二轮已补上（40px 红底白字），并同时去掉了「回购分类」下拉。
2. **正文保持 16px，不跟到设计图的 ~20px。** 设计画布是 1920 且正文实测量到 20px；
   本站现有字号体系经过对比度与密度验收，整体放大是另一件事，需要单独决定。
3. **顶栏保留「卡牌 / 公告」导航。** 设计图的顶栏没有内容导航（可能落在二级导航或页脚），
   直接删掉会让两个主入口消失，因此保留为白字链接（`xl` 起显示）。
4. **顶栏保留语言与主题开关。** 设计图没有这两个；它们是本站已验收的必备项
   （主市场是日语，语言开关藏进抽屉等于没做），因此以白字压在红底上。
5. **价格红沿用 `#dc0a3c` 而非 `#db261d`。** 数值上只差几个点、肉眼不可辨，
   但 `#dc0a3c` 的 5.06:1（白）/ 4.83:1（页底）是已验收的对比度余量；
   `#db261d` 作为**文字色**在页底只有 4.52:1，擦线。红底填充仍用 `#db261d`。
6. **页脚世界地图底纹不做。** 它是图片素材，不是样式。
7. **门店页左图不做出血。** 设计稿出血到画布左边缘，本站内容列居中，负 margin 出血
   会在有滚动条的视口下错位。
8. **门店照片缺失时的处理**（第三轮改过）：最初是「没照片就换成信息+地图双列」，
   但那等于同一页有两套版面。现在左列恒定是图位——没照片就放「暂无图片」占位，
   骨架不随数据变形。

## 复核方式

`.scratch/ui-redesign/verify.mjs` 对真实渲染的计算样式做断言（顶栏色/高、页脚色、页面底色、
内容列宽、价格色），`.scratch/ui-redesign/sweep.mjs` 跑 3 宽度 × 2 主题 × 8 页的溢出与控制台检查。
