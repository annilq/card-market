# header/footer 导航重整验收（2026-10-27）

四项改动：留言移入 footer、店铺收成 SHOP 图标并贴搜索右侧、X 图标化、
语言与主题移到最右作为辅助设置。

## 设计取舍

- **X 与 SHOP 是搜索的附属组。** 参考图里就是「搜索框 | X | SHOP」一组，
  所以两处顶栏结构里它们都紧挨搜索：≥1024 在第一行，不足 1024 整组下移第二行。
- **为什么不足 1024 时下移。** 640–1023 的第一行要同时容纳导航、
  搜索、X/SHOP、语言、主题；量测下搜索框只剩 54px，占位符被裁。
  下移后同一档位搜索框为 439px。
- **SHOP 带文字只在 ≥1024。** 16px 描边图标单独出现辨识度不足，
  文字版只给有空间的宽度，其余退化为方形图标（36px，与 X 等宽）。
- **语言与主题的归处。** 桌面留最右、压低权重（muted + 细边框），
  它们不参与导航链路。手机（<640）收进汉堡抽屉，末尾一行「偏好设置」
  与两个控件，避免顶栏挤掉 logo 与搜索。
- **X 在 footer 去重。** 原来 footer 有一行纯文本「X：@cardmarket」，
  图标进 header 后语义重复，删掉纯文本，只保留可点击图标。

## 行为验证

- header 内已无留言入口：可见链接为 站点名 / 卡牌 / 公告 / X / SHOP。
- footer 站内链接行：留言咨询 + 四个信息页，顺序固定，5 个链接点击高度均为 28px。
- 搜索：从 `/cards?ip=1&sort=price_asc` 提交「皮卡」→ `?ip=1&sort=price_asc&q=皮卡&page=1`，筛选与排序保留。
- 店铺图标点击 → `/shops`。
- X 链接 `https://x.com/cardmarket`，`target=_blank`，`rel="me noreferrer"`。
- 三语：ja 为「カード / お知らせ / SHOP」，footer 首项「お問い合わせ」；en 为「Cards / News / SHOP」，「Contact」。
- 全站扫描：5 视口 × 10 页面，横向溢出 0、小于 24px 的点击目标 0、控制台错误 0。
- `node scripts/check-i18n.mjs` 全部通过。

## 附带修掉的两处既有可达性问题

改动让这两处更容易被命中，一并处理：

1. footer 链接点击高度只有 16px（WCAG 2.5.8 要求 24px）→ 加 `inline-flex py-1.5`，28px。
2. 桌面导航「卡牌 / 公告」同样只有 16px → 加 `inline-flex py-2`，32px。
