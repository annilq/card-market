# 筛选区第三轮优化验收（2026-10-27）

三项：标签与下拉间距、「重置」按钮、「全部」文案与样式统一。

## 1. 标签与下拉的间距

根因不是 gap，而是标签固定 `w-20`（80px）：「分类」「类型」「排序」只有 24px 宽，
后面空出 56px，看起来就是间距过大。

改法：标签宽度改为内容自适应，gap 从 8px 收到 6px。

但只改这一处会引出第二个问题：标签宽度不一后，四个下拉若也随内容走，
宽度会从 78px 到 161px 各不相同。因此给下拉统一 `w-44`（176px）。

| 检查 | 结果 |
| --- | --- |
| 标签与下拉间距（三语 × 桌面/手机） | 全部 6px |
| 四个下拉宽度 | 桌面全部 176px；手机占满整行 304–328px |
| 横向溢出 | 0 |

### 下拉宽度是被截断逼出来的

第一次给 `w-32`（128px）时看着整齐，但实测可用内宽只有 78px，而最长选项需要：

| 语言 | 最长选项 | 文本宽 | 128px 下是否截断 |
| --- | --- | --- | --- |
| zh | 价格：高→低 | 83px | 是 |
| ja | パッケージあり | 98px | 是 |
| en | Price: high to low | 111px | 是 |

加宽到 `w-44` 后可用内宽 126px，三语均不截断。

### 手机端

`w-44` 固定在 390 宽屏幕上会留一大块空白，所以手机上改成占满整行
（每行一个筛选，标签在左、下拉填满剩余宽度）。

## 2. 重置按钮

- 位置：标题行右侧，在「全部」左边。
- 语义：清空全部筛选，回到默认排序与全部卡牌（`navigate({ search: {} })`）。
- 无筛选时禁用而不是隐藏，按钮位置不会在筛选前后跳动。
- 用 `button` 而不是链接：它是操作，不是导航。

| 状态 | 重置按钮 |
| --- | --- |
| 无筛选（`/`） | 禁用，浅色 |
| 有筛选（`?ip=1&series=1&type=raw&sort=price_asc`） | 可用 |
| 点击后 | URL 变回 `/`，按钮重新禁用 |

判断「有没有可重置的东西」用 `DEFAULT_CARD_SORT` 常量而不是写死 `'price_desc'`，
默认排序将来变化时这里不会漏改。

## 3. 「全部」文案与样式

上一轮我用了「全部卡牌」并做成胶囊按钮，与其他两个区块的「全部 →」不是一套。

- 文案改回 `viewAll`（全部 → / すべて → / View all →），与「通知公告」「高价买取」同源。
- 样式改为纯文字加下划线 hover，与那两处完全一致：
  实测 font-size 14px、color 相同、无边框无内边距。

「重置」保持纯文字但样式独立（灰、禁用态更浅），避免与「全部」这个导航链接混淆。
