# 筛选区 UI 优化验收（2026-10-27）

三项改动：标签与下拉同行、标题行加「全部卡牌」按钮、三语覆盖。

## 标签与下拉同一行

参考图就是这个排版。桌面 ≥1024 四列并排，手机单列（标签在左、下拉占满剩余宽度）。

标签给了固定宽度 `w-20`（80px）。不设的话三种语言各自为政：

| 语言 | 最宽标签 | 实测宽度 |
| --- | --- | --- |
| zh | 回购分类 | 48px |
| en | Category | 52px |
| ja | 買取カテゴリ | 72px |

不统一宽度时，四个下拉在同一条行内宽度分别是 217 / 241 / 241 / 241，右边缘参差不齐。
统一后四列下拉宽度完全一致（185px），左边缘与右边缘都对齐。

## 「全部卡牌」按钮

- 位置：标题行右侧，与「通知公告」「高价买取」的标题行结构一致。
- 文案用「全部卡牌 / すべてのカード / All cards」，不是「全部」。
  筛选语境下的「全部」会被读成「清空筛选」，而它是跳转到卡牌列表页。
- 用 `Link` 而不是 `button`：它是导航，键盘与读屏应把它当链接。
- 从带筛选的首页点击后会丢掉查询串，落到干净的 `/cards`。

实测跳转与语言前缀：

| 起点 | 点击后 |
| --- | --- |
| `/?ip=1&series=1&type=raw&sort=price_asc` | `/cards` |
| `/ja/?ip=2` | `/ja/cards` |
| `/en/?type=packaged` | `/en/cards` |

## 国际化

新增一个文案键 `catalogBrowseAll`，三语齐全：

| | zh | ja | en |
| --- | --- | --- | --- |
| 标题 | 卡牌筛选 | カードを絞り込む | Filter cards |
| 全部按钮 | 全部卡牌 | すべてのカード | All cards |

`localeParams` 由首页显式传入组件，而不是让 `to="/{-$locale}/..."` 从当前路径
继承语言段——404 页里那个段是非法值，继承会生成二次 404。

## 顺带修的两处

1. **外层多套了一层 `<section>`。** `CatalogFilters` 自带 `<section>`，首页又包了一层，
   两个同名的 landmark 对读屏是干扰。组件内改成 `div role="group"`。
2. **焦点环缺失。** 站内其他交互元素都有 `focus-visible` 焦点样式，新加的链接和
   四个下拉没有，键盘用户看不到焦点在哪。已补齐；用真实 Tab 键验证，
   聚焦到「全部卡牌」时 `outline: 2px solid`。
