# 范围边界：内容展示型定位

Type: task
Status: resolved
Blocked by:

## Question

本项目的范围边界如何界定？哪些能力明确不在本次交付内？

## Answer

已依 `spec.md` 将本项目定位为**内容展示型网站**（卡牌展示 + 回购信息 + 公告 / 店铺信息 / 访客留言），不构建交易闭环。明确排除：

- 购物车与在线下单
- 在线支付
- 订单及物流管理
- 库存交易系统
- 复杂会员体系

任何超出"内容展示 + 回购信息"定位的交易能力均不在本次交付范围。这一边界是后续所有 ticket 的范围基准：frontier 只向 destination 推进，不越过该边界。
