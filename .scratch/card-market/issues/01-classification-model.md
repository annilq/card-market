# 卡牌分类的层级与字段枚举如何建模

Type: grilling
Status: open
Blocked by:

## Question

卡牌分类应如何在数据模型中表达？`spec.md` 列出"卡牌类别(宝可梦) / 系列分类(MEGA) / 卡牌类型 / 稀有程度 / 排序 / 状态"多个维度，但层级与枚举未定。需要决定：

1. 分类是单层还是多层（类别 → 系列）？
2. "卡牌类型""稀有程度"是分类维度，还是卡牌自身的属性字段？
3. 用一张带 `dimension` 字段的通用分类表，还是多张独立表（category / series / type / rarity）？
4. 各维度的可选枚举值由谁维护（后台配置化 vs 硬编码）？

该决策直接影响 `cards` 表的字段与关系，以及前台筛选器的设计，须在本 ticket 解决后再落地数据模型。
