# 页脚改版验收（2026-10-27）

## 结构

```
<footer>
  站内链接（居中）：留言咨询 · 运营信息 · 个人信息收集 · 利用规则 · 数据使用
  ────────────── 分割线 ──────────────
  logo（h-16 w-40，未上传时留同等空位）
  版权行
</footer>
```

## 删除的内容

下面五段文字原本在页脚的三列网格里，本次全部移除：

| 内容 | 来源字段 | 状态 |
| --- | --- | --- |
| 卡牌回购站（站名重复） | `site_settings.site_name` | 页脚已移除，header 与版权行仍在用 |
| 专注宝可梦 / 游戏王 / 龙珠等卡牌展示与高价回购。 | `site_settings.intro` | 页脚已移除 |
| 邮箱：shop@example.com | `site_settings.contact_email` | 页脚已移除 |
| 店铺地址与营业时间见「店铺」页 | 界面文案 `shopsHint` | 文案键已删除（三语） |
| 本站展示数据仅供鉴赏，交易以实际鉴定为准。 | `site_settings.data_notice` | 页脚已移除 |
| 我们仅将联系方式用于回复您的咨询。 | `site_settings.privacy_policy` | 页脚已移除 |

后台字段没有删。Directus 里这些值仍在，只是前端不再渲染；
以后想放回页脚，加几行 JSX 即可，不需要改数据模型。

## 量测结果

| 检查 | zh | ja | en |
| --- | --- | --- | --- |
| 链接数量 | 5 | 5 | 5 |
| 链接点击高度 | 28px | 28px | 28px |
| 链接区中心偏移（相对视口中心） | -7px | -7px | -7px |
| 页脚高度 | 234px | 234px | 234px |

中心偏移 -7px 来自 `gap-x-5` 凑不成整行的余量，肉眼不可见，
不影响「居中展示」这一要求。

其余检查：

- 页脚可见文本只剩链接行与版权行，五段被删文案在 footer 内均为 0 处。
- 全站扫描（5 视口 × 10 页面）：横向溢出 0、点击目标过小 0、控制台错误 0。
- `node scripts/check-i18n.mjs` 全部通过。

## logo 的两种状态都实测过

| 状态 | 结果 |
| --- | --- |
| 未上传（`logo = null`） | 留 160×64 空位，版权行位置与有图时一致 |
| 宽版素材（480×160） | 按 160×64 显示，居中 |
| 竖版素材（1280×1707） | 按 48×64 显示，居中，未撑高页脚 |

测试用的临时 logo 文件已从 Directus 删除，`site_settings.logo` 已复位为 `null`。

## 注意：loader 里仍会传这四个字段

页脚不再使用 `intro / contact_email / data_notice / privacy_policy`，
但 `getSiteSettings()` 仍是 `fields=*`，所以这些值依旧出现在
每一页的 SSR 序列化数据里（`$R` 数据块，不是可见文本）。

不影响渲染与安全（都是公开内容），只是每页多传几十字节。
要清掉就把 `getSiteSettings` 的 fields 收窄到实际使用的
`site_name, logo, x_account`——这属于数据层收敛，本次没做。
