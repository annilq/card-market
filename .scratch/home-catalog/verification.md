# 首页卡牌列表筛选验收（2026-10-27）

## 四个下拉的映射

参考图里的四项在数据模型里没有一一对应的现成字段，映射如下：

| 参考图 | 本项目 | 数据来源 | 写入 URL |
| --- | --- | --- | --- |
| 回购分类 | 回购分类 | `ips` 表 | `?ip=<id>` |
| 分类 | 分类（系列） | `series` 表，随已选 IP 收窄 | `?series=<id>` |
| 类型 | 类型 | `cards.card_status`（裸卡 / 有包装） | `?type=raw\|packaged` |
| 排序 | 排序 | 价格升降 + 上架时间正倒序 | `?sort=...` |

「类型」用的是 `card_status`：`card_types` 这个维度在 01 号决策里已明确删除，
`card_status` 是库里唯一现成的「类型」性质字段。

## 状态放在 URL

筛选写进查询串而不是组件 state，因此可分享、可后退、刷新不丢；
loader 直接读查询串，首屏就是过滤后的结果，不会先渲染全部再收窄。

canonical 仍指向 `/`（不含查询串），十几种筛法不会被搜索引擎算成重复页面。

## 实测（CDP，生产构建）

初始与逐项筛选：

| 操作 | URL | 结果条数 | 分类下拉候选 |
| --- | --- | --- | --- |
| 初始 | `/` | 6 | 朱紫 / 主力系列 / 主线 / 剑盾 |
| 选回购分类=宝可梦 | `?ip=1` | 3 | 朱紫 / 剑盾（已收窄） |
| 再选分类=朱紫 | `?ip=1&series=1` | 2 | 朱紫 / 剑盾 |
| 排序改价格低→高 | `?ip=1&series=1&sort=price_asc` | 2 | 朱紫 / 剑盾 |
| 换回购分类=游戏王 | `?ip=2&sort=price_asc` | 2 | 主力系列（分类被清空并重新收窄） |

换 IP 时 `series` 会被清掉：新 IP 下可能没有原系列，留着会查不到任何卡。

## 标题

「最新上架」这个标题已删除，卡牌网格上方只剩「共 N 张」计数。
注意「最新上架」四个字仍会出现在**排序下拉的选项**里，那是排序值，不是标题。

## 下拉箭头

Tailwind 任意值语法 `bg-[url(...)]` 构建后生成的 `background-image` 是 `none`
（实测），箭头不显示。改用内联 style，深色主题下同样可见。
